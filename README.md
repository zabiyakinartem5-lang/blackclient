# Legit Client (Fabric 1.21.4)

Красивый клиентский мод с анимированным ClickGUI и настройкой цветов.

Функции:
- Visual: Zoom, Fullbright, Freelook, Aspect Ratio (растяг: 1.33 = 4:3, 1.25 = 5:4), Motion Blur (экспериментально), FOV Offset, Time Changer (время суток только у вас на экране)
- Movement: ToggleSprint, ToggleSneak
- HUD: FPS, координаты, CPS, пинг, скорость, направление, часы, броня; Keystrokes (WASD, мышь, пробел); эффекты зелий с таймерами; Module List (список включённых модулей); Watermark; биом
- Client → Theme: два цвета (оттенок 0-360), насыщенность, яркость, радужный режим со скоростью, прозрачность панелей
Никаких функций с нечестным преимуществом (нет килауры, ESP, X-Ray и т.п.).

## Новое
- Главное меню (Client → Main Menu): анимированный фон в цветах темы, кнопки, карточка игрока. Выравнивание, свечение, затемнение, ширина, высота кнопок и скругление настраиваются. Выключите модуль, чтобы вернуть ванильное меню.
- Меню клиента компактное: вкладки Visual / Movement / HUD / PvP / Client, колёсико прокручивает список.
- Кнопка Edit HUD в меню: любые блоки HUD перетаскиваются мышью (ПКМ - вернуть на место, Reset all - всё сбросить).
- Watermark: FPS, пинг и часы (включаются в настройках).
- HUD: IP сервера, номер дня, RAM. No Hurt Cam. PvP-вкладка: Target HUD, Combo Counter, PvP Items.

- Свой прицел (Visual → Crosshair): зазор, длина, толщина, точка, обводка, цвет темы.
- Chat Time: время перед каждым сообщением в чате.
- Move Status: плашка Walking / Sprinting / Sneaking. Death Point: координаты и расстояние до места последней смерти.

- Вкладки меню: **Friends** (список друзей, список в сети на экране, уведомления о входе/выходе), **Marks** (метки: добавить на месте или клавишей B, расстояние и направление на экране, скрыть/удалить), **Configs** (сохранить/загрузить/удалить профили настроек).
- **Inventory HUD** (ваш инвентарь на экране) и **Staff List** (персонал онлайн по пометкам в Tab-списке).
- Данные лежат в `config/`: legitclient.json, legitclient_friends.json, legitclient_marks.json, legitclient_profiles/.
- Block ESP (подсветка блоков сквозь стены) в клиент не входит намеренно: это аналог X-Ray.

- **Бинды внутри клиента:** Client → Keybinds (меню, Zoom, Freelook, метка) и строка **Bind** у каждого модуля. Клик по кнопке, затем нажмите клавишу. ПКМ или Backspace сбрасывает, Esc отменяет. Ванильные настройки управления для клиента больше не нужны.
- **Закругление и прозрачность** (Client → Theme): Corner radius (0 = прямые углы) действует на все панели, кнопки и блоки HUD; Menu opacity и HUD opacity задают прозрачность меню и блоков.
- **Potion HUD** с полосой оставшегося времени.
- **Snow:** снежинки на экране и в меню, по желанию снег вокруг игрока.
- **Starry Sky:** вечная ночь и яркие звёзды (только у вас). **Atmosphere:** цветная тонировка и виньетка. Звёздный фон и падающие звёзды в главном меню.
- Настоящие шейдеры (GLSL) мод не поддерживает: для них нужен Iris и шейдерпак.

## Версия игры
Мод собран под Minecraft 1.21.4. На другой версии (например 1.21.11) он не запустится: нужен профиль 1.21.4 с Fabric Loader и Fabric API.

## Сборка
Нужны JDK 21, Gradle 8.12+ и интернет. (Либо скопируйте `gradlew`, `gradlew.bat` и папку `gradle/`
из https://github.com/FabricMC/fabric-example-mod и запускайте `./gradlew build`.)

    gradle build           # нужен Gradle 8.12+

Готовый мод: `build/libs/legitclient-1.0.0.jar` (не `-sources`).
Положите его в папку `mods` вместе с Fabric Loader и Fabric API для 1.21.4.

## Управление
| Клавиша      | Действие                          |
|--------------|-----------------------------------|
| Right Shift  | Открыть / закрыть меню            |
| C (держать)  | Zoom, колёсико меняет кратность   |
| Left Alt     | Freelook (держать)                |

В меню: ЛКМ по модулю - включить, ПКМ - настройки (слайдеры, переключатели).
Все клавиши меняются в настройках управления. Конфиг: `config/legitclient.json`.

## Другая версия Minecraft
Поменяйте значения в `gradle.properties` (https://fabricmc.net/develop). Для разных версий могут
отличаться сигнатуры в миксинах (`GameRendererMixin`, `CameraMixin`) и в GUI (`DrawContext`).

## Важно
Правила серверов разные: Freelook и Fullbright на некоторых серверах запрещены. Проверяйте правила.
